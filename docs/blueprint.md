# 알카노이드 (Arkanoid) 블루프린트

## 1. 프로젝트 개요

### 기본 정보
- **프로젝트명**: 알카노이드 (Arkanoid)
- **프로젝트 유형**: 웹 브라우저 게임 (React + Canvas)
- **핵심 기능**: 벽돌 깨기 게임으로, 패들을 조종하여 볼을 튕기고 블록을 파괴하는 아케이드 게임
- **타겟 사용자**: Casual gamers, 레트로 게임 팬

### 비주얼 스타일
- **테마**: 다크 네온 사이버펑크
- **배경색**: `#1a1a2e` (짙은 네이비)
- **주요 색상 팔레트**:
  - 배경: `#111827`, `#1a1a2e`
  - UI 강조: `#3498db` (블루), `#2ecc71` (그린), `#f1c40f` (옐로우)
  - 위험 표시: `#e74c3c` (레드)

## 3. 게임 시스템 설계

### 3.1 게임 오브젝트

#### 패들 (Paddle)
| 속성 | 기본값 | 설명 |
|------|--------|------|
| 너비 | 100px | 게임 진행 중 고정 |
| 높이 | 15px | - |
| 속도 | 8px/frame | - |
| 색상 | `#3498db` | 블루 |
| 위치 | 화면 하단에서 20px | - |

#### 볼 (Ball)
| 속성 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| 반지름 | number | 8px | - |
| 색상 | string | 흰색/보라색 | 흰색=플레이어, 보라=추가볼 |
| isPlayerBall | boolean | true | 플레이어 볼 여부 |

**볼 색상 구분**:
- **흰색 볼**: 플레이어 볼 (주요 볼)
  - 이 볼이 바닥에 떨어지면 생명-1
  - 글로우 효과 추가
- **보라색 볼**: 추가 생성 볼
  - 특정 블록 파괴 시 생성
  - 바닥에 떨어져도 생명에 영향 없음
  - 약간 작은 크기 (반지름 * 0.8)

#### 블록 (Brick)
| 속성 | 기본값 | 설명 |
|------|--------|------|
| 행 | 5 | - |
| 열 | 10 | - |
| 크기 | (GAME_WIDTH - 40) / 10 | 가로, 25px 세로 |
| 간격 | 5px | - |

**블록 타입**:
| 색상 | 점수 | 추가 볼 생성 | 위치 |
|------|------|--------------|------|
| 흰색 (`#ecf0f1`) | 5 × 레벨 | ✗ | 행 0, 5 |
| 주황색 (`#f39c12`) | 10 × 레벨 | ✓ | 행 1, 6 |
| 파란색 (`#3498db`) | 8 × 레벨 | ✓ | 행 2, 7 |
| 빨간색 (`#e74c3c`) | 15 × 레벨 | ✓ | 행 3, 8 |
| 노란색 (`#f1c40f`) | 12 × 레벨 | ✗ | 행 4, 9 |

### 3.2 게임 상태

#### GamePhase 타입
```typescript
type GamePhase = 'start' | 'playing' | 'roundComplete' | 'gameOver' | 'victory';
```

#### GameState 구조
```typescript
interface GameState {
  paddle: { x, width, speed, baseSpeed };
  balls: Ball[];           // 모든 볼 배열
  bricks: Brick[];         // 모든 블록 배열
  hp: number;              // 현재 HP (100)
  maxHp: number;           // 최대 HP (100)
  score: number;           // 누적 점수
  lives: number;           // 현재 생명 (3)
  maxLives: number;        // 최대 생명 (3)
  level: number;           // 현재 라운드 (1-10)
  phase: GamePhase;        // 게임 단계
  roundStats: {
    blocksDestroyed: number;
    ballsAdded: number;
    scoreEarned: number;
  };
}
```

### 3.3 게임 흐름

```
[시작 화면]
    │
    │ SPACE 키
    ▼
[게임 진행 - 라운드 1-10]
    │
    ├── 블록 전부 파괴 → [라운드 완료 화면] ──→ SPACE 키 ──→ 다음 라운드
    │
    ├── 흰색 볼 바닥 탈출 → 생명-1
    │       │
    │       ├── 생명 > 0 → 새 흰색 볼 생성 → 게임 계속
    │       │
    │       └── 생명 = 0 → [게임 오버 화면]
    │
    └── 생명 0 → [게임 오버 화면]
              │
              └── SPACE 키 → [시작 화면]

[10라운드 완료]
    │
    ▼
[승리 화면]
    │
    └── SPACE 키 → [시작 화면]
```

### 3.4 물리 엔진

#### 볼 이동
```typescript
// 매 프레임 위치 업데이트
ball.x += ball.vx * deltaTime;
ball.y += ball.vy * deltaTime;
```

#### 벽 충돌
- 좌/우 벽: vx 반전
- 상단 벽: vy 반전
- 하단 벽: 볼 타입에 따라 처리 (플레이어 볼=생명-1, 추가 볼=제거)

#### 패들 충돌
- 볼이 패들 위에서 아래로 이동 중일 때만 충돌 감지
- 충돌 위치에 따라 반사 각도 조절 (패들 중앙=수직, 끝=사선)
```typescript
const hitPos = (ball.x - paddle.x) / paddle.width;  // 0~1
const angle = (hitPos - 0.5) * Math.PI * 0.7;       // -63° ~ +63°
```

#### 블록 충돌
- AABB 충돌 감지
- 충돌 방향 결정 (좌/우 vs 상/하)하여 해당 축의 속도 반전
- 블록 파괴 시 spawnsBall 플래그 확인 → 추가 볼 생성

### 3.5 레벨 시스템

| 라운드 | 속도 배수 | 블록 점수 |
|--------|-----------|-----------|
| 1 | 1.00 | × 1 |
| 2 | 1.15 | × 2 |
| 3 | 1.30 | × 3 |
| ... | +0.15/레벨 | ... |
| 10 | 2.35 | × 10 |

**라운드 완료 보상**: HP +30 (최대 100)

## 5. 컨트롤

| 입력 | 동작 |
|------|------|
| `←` 또는 `A` | 패들 왼쪽 이동 |
| `→` 또는 `D` | 패들 오른쪽 이동 |
| `SPACE` (시작 화면) | 게임 시작 |
| `SPACE` (라운드 완료) | 다음 라운드 |
| `SPACE` (게임오버/승리) | 처음부터 재시작 |
